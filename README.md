# Breaker Wars

Breaker Wars is a prototype game made in the style of a game jam, but without the actual event. It was made over the course of a week in just a couple hours per day.  

The game is a local multiplayer brick breaker versus game where breaking bricks allows you to collect mana to cast spells that alter the game. Missing the ball, allowing bricks to reach the bottom of the play area, or when the opponent hits certain bricks cause you to take damage. The game is over when one player reaches 0 HP.
